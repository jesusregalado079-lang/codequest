# Computer Quest — Parent Setup Checklist

Status: DRAFT for Jesse's review · 2026-09-16 · Windows/Microsoft steps fact-checked against Microsoft support pages (Codex review + spot-check)
Do this once before Lesson 1. It takes about 45-60 minutes.

Setup decided:
- **One shared Windows account** for both boys.
- **Separate CodeQuest profiles**, each locked with a 3-picture code.
- **Separate folders** in Documents.

---

## 1. Check which Windows the computer runs
- ☐ Start → Settings ⚙️ → System → **About** → *Windows specifications* → **Edition**.
- ☐ **If it says Windows 10:**
  - Free support ended **October 14, 2025**.
  - Microsoft's consumer **Extended Security Updates (ESU)** program can keep an enrolled Windows 10 PC protected **through October 12, 2027**.
  - Make sure the PC is either enrolled in ESU or upgraded to Windows 11 before the boys go online.
  - Upgrade check: Start → Settings → **Update & Security → Windows Update** tells you whether the PC can take Windows 11.
  - The lessons work on both versions.
  - Source: [Microsoft Support](https://support.microsoft.com/en-us/windows/deployment/updates-lifecycle/windows-10-support-has-ended-on-october-14-2025)
- ☐ Run **Windows Update** until it says you're up to date.

## 2. Your account stays the boss
- ☐ Your own account is the **administrator** and has a password or PIN the boys don't know.
- ☐ The boys' shared account is a **Standard** user (not administrator). That alone blocks most installs and system changes.

## 3. One shared kids' account
- ☐ Create one child Microsoft account for the boys to share (step 4). Then add it to the PC:
  - Windows 11: Settings → Accounts → **Family** → **Add someone**
  - Windows 10: Settings → Accounts → **Family & other users** → **Add a family member**
- Filters and screen time apply to **both boys together**, so set them for the **younger** boy.
- ☐ In File Explorer → **Documents**, make **one folder per boy**, named with his CodeQuest nickname. Every lesson has him work only inside his own folder, so their stuff never mixes and your checks show who did what.

## 4. Microsoft Family Safety (free)
- ☐ Go to **account.microsoft.com/family** and sign in with your Microsoft account.
- ☐ Add the kids' account as a **child** member. You create it; depending on the age entered and your region, Microsoft may ask you for adult consent.
- ☐ Web filtering: on the child's card, open **Edge** → turn on **Filter inappropriate websites and searches**.
  - Filtering only works in **Microsoft Edge** while the kids' account is signed in. That's why the lessons use Edge.
  - Other browsers are blocked by default. **Leave them blocked.** Don't unblock them in *App and game filters*.
- ☐ Optional, stricter: turn on **Only use allowed websites** and add:
  - `https://jesusregalado079-lang.github.io/codequest/` (CodeQuest itself; without this, the lessons won't load)
  - any kids' sites you want for G5 and S5 (for example an encyclopedia or animal-facts site you trust)
- ☐ **Spending:** require your approval for purchases. (This covers the Microsoft Store.)
- ☐ **Screen time:** set a schedule that fits both boys' lessons plus typing practice.
- ☐ **Activity reporting:** turn it on if you want a weekly email.
- Source: [Family Safety web filtering](https://support.microsoft.com/en-us/family-safety/filter-websites-and-searches-using-microsoft-family-safety)

## 5. Microsoft Edge
- ☐ Sign Edge into the kids' account so filtering applies.
- ☐ Open CodeQuest and add it to the **favorites bar** so it's one click away.
- ☐ Check that **File Explorer** and **Edge** are on the taskbar. If one is missing: open it, right-click its taskbar icon → **Pin to taskbar**.

## 6. Notepad (used in most lessons)
- ☐ **Windows 11:** open Notepad → **Settings** (gear icon) → **When Notepad starts** → choose **Start new session and discard unsaved changes**.
  - The default, *Continue previous session*, reopens old unsaved text. That would confuse the lessons and could show one brother's practice text to the other.
- Windows 10 Notepad has no such setting, so nothing to do there.
- If Notepad shows a Copilot or AI button, the lessons don't use it.

## 7. OneDrive and the Documents folder
- On a Microsoft account, OneDrive may be **backing up** Documents, which makes it live under OneDrive.
- The lessons still work, because "Documents" still shows on the left in File Explorer.
- ☐ Optional, simpler: OneDrive icon (by the clock) → Settings → **Sync and backup** → **Manage backup** → turn off Documents.
  - **Read the next choice carefully.** It asks whether files stay in OneDrive or on this PC. Files that are only in the cloud may need downloading first.

## 8. The keyboard and mouse
- ☐ Find the **Windows key ⊞** with each boy, so the lessons land.
- ☐ **Laptop?** Check whether **F2** needs **Fn** held down (G4 and S3 use F2).
- ☐ **Laptop?** A plug-in mouse makes the early lessons much easier than a touchpad.

## 9. The spot
- ☐ The computer sits somewhere you can see the screen from nearby.
- ☐ Chair height puts elbows level with the keyboard. The top of the screen is about eye level.
- ☐ Tape a card by the screen: **STOP. Don't click. Tell a grown-up.**

## 10. CodeQuest itself (after Phase 1 is built)
- ☐ Set your 4-digit **parent PIN**. It's a lock against curious fingers, not real security; your Windows admin password is the real lock.
- ☐ Each boy creates his character and a **nickname** (not his full name). Use the same nickname as his Documents folder.
- ☐ Each boy picks his **3-picture code**. It stops casual profile-switching, not a determined brother. If he forgets it, reset it from the parent area.
- ☐ Assign each boy's quest line (9yo track / 10yo track).

## Each lesson day (2 minutes)
**Before:**
- ☐ The kids' account is signed in.
- ☐ Edge opens CodeQuest.
- ☐ The right boy picked his own profile.
- ☐ You're within earshot.

**After:**
- ☐ When he calls you, enter your PIN and tick the real-task checks you actually saw.
- ☐ Open the report → **Copy summary** (one boy or both) → paste it to me, and we decide what's next.
